Live Settings

When automation is on, a 4h Price Levels Signal whose rule is checked below places a real Polymarket order for that window (same as Virtual Trades). Defaults keep automation off until you opt in.

Automation OFF

Automation

When off, no live orders are placed — even if a signal fires. Turn on only after Account is connected and rules are selected.

Sizing & limits

Default is always 10% of live CLOB collateral — never the full balance unless you change this field. Stake is recalculated at order time.

Next trade will be placed for 10% of current CLOB collateral.

Dollar preview uses the CLOB balance from Live Account (refresh there first). Daily loss limit is a kill switch once the bot is live.

Allowed signal rules

Rules match crypto_price.signal_rule (1–21). None selected = no live trades, even with automation on.
